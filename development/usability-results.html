USABILITY RESULTS

Observations

The user tried to navigate backward through prompts, functionality which is not currently possible.

The user was not aware that they could select multiple categories.

The user said they thought the questions were asking for "more personal" and "less broad" responses and reflections.

The user expressed uncertainty as to the "point" of the project.

Question Responses

Identify aspects of your project that need to be improved.

The user flow needs to be improved, first and foremost. Backwards movement should be allowed for. What is expected of the user, such as the expectation that they select more than one category, should be made clearer.

Can users figure out how to navigate/interact with your project?

Yes, they navigated through the page with ease. They pushed the correct buttons at the correct times. They expected additional options for movement, as previously mentioned.

Does the project impact the user the way you want it to? (Does it have the right message or communicate what you want it to?)

No, it does not. The user questioned the point of the project. I had to explain that it is meant to be reflective. I think more of this will become clear when other user data is available and visualized.

What modifications need to be made to interactions, visuals or other elements of the project to make it stronger?

As previously stated, I need to allow for movement in both directions; it is currently too linear. I need to let the user know that they can (and are encouraged to) select mulitple options when presented with a "cluster" or "cloud".

Plan of how you will update your capstone project based on the feedback.

I will update the user prompts to make it clearer that multiple categories can be selected. I will add the option to go backwards to a previous prompt. I will allow the user to restart without needing to refresh the page.
